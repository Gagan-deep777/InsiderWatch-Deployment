IT OPERATIONS & ENDPOINT SECURITY GUIDELINES

Version: 1.3
Classification: MEDIUM | Internal
Owner: IT Operations
Review date: 20 November 2026

1. ACCOUNT SECURITY
• Use a unique password for each company service.
• Enable multi-factor authentication where available.
• Never share passwords, session cookies, API tokens or recovery codes.
• Report unexpected MFA prompts immediately.
• Administrators must use separate privileged accounts for administrative work.

2. DEVICE SECURITY
• Keep operating systems, browsers and endpoint protection updated.
• Enable automatic screen locking.
• Encrypt company laptops where supported.
• Do not connect unknown USB devices.
• Report lost or stolen devices as soon as possible.

3. NETWORK AND REMOTE ACCESS
• Use approved VPN or secure remote-access services.
• Avoid untrusted public Wi-Fi for sensitive work.
• Do not expose development servers directly to the public internet without approval.
• Restrict inbound firewall rules to required ports and trusted sources.

4. SOFTWARE AND DEVELOPMENT
• Install software from trusted and approved sources.
• Keep dependencies patched and review security advisories.
• Do not commit secrets or production data to Git repositories.
• Review code before merging and test changes before deployment.
• Store environment-specific secrets outside source code.

5. BACKUP AND RECOVERY
• Critical data must have scheduled backups.
• Backup jobs must be monitored for success and failure.
• Perform periodic restore tests; a backup is not verified until restoration is tested.
• Document recovery owners, dependencies and recovery priorities.

6. INCIDENT RESPONSE
1. Report the event to the security team.
2. Preserve relevant logs and timestamps.
3. Isolate a suspected compromised endpoint only under authorised guidance.
4. Reset credentials or revoke sessions through the approved process.
5. Record containment, recovery and lessons learned.
